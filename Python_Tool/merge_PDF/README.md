# PDF 智慧合併工具 (PDF Merger Pro)

## 📌 功能特色
1. **多檔案合併**：支援多選個別 `.pdf` 檔案加入清單。
2. **指定資料夾批次載入**：一鍵掃描整個資料夾內的所有 PDF 檔案（可選是否包含子資料夾）。
3. **智慧自然排序**：自動依據數值檔名進行自然排序（例如 `file1, file2, file10`，而非傳統字典順序 `file1, file10, file2`）。
4. **自訂清單順序**：支援項目上移、下移、移至頂部/底部、反轉順序與字典排序。
5. **指定合併頁面範圍**：雙擊清單項目或點選「設定頁面」，即可設定如 `1-5`, `1,3,5-8`, `全部` 等範圍。
6. **自動建立書籤目錄 (Bookmarks)**：合併後自動依來源檔名建立章節導航書籤，方便在 PDF 閱讀器中切換。
7. **背景多執行緒處理**：介面流暢不卡頓，具備即時進度條與詳細日誌。
8. **一鍵開啟**：完成後可直接開啟輸出 PDF 或所在資料夾。

## 🚀 啟動方式
- 直接執行 `run.bat`
- 或於終端機執行：
  ```bash
  python pdf_merger_gui.py
  ```

## 📦 依賴套件
- Python 3.8+
- `pypdf` (`pip install pypdf`)
- `tkinter` (Python 內建)
